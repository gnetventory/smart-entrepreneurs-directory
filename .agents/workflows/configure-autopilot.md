# Workflow: Configure Autopilot (/configure-autopilot)
1. Read existing codebase files if present.
2. Ask the user 3 micro-interview questions in a single prompt:
   a. System Goal & Target Audience
   b. Visual Vibe / Archetype
   c. Hosting & Operational Constraints
3. Update `.context/01_PRODUCT_AND_ROADMAP.md` through `.context/04_SECURITY_AND_OPS.md`.
4. Log initialization ADR in `.context/05_STATE.md`.
