1. Executive Summary & Scope

1.1 Purpose & Mission

WhatsApp and Telegram entrepreneur groups suffer from rapid message turnover. Critical intros, skill offers, geographic locations, and business needs scroll past and are permanently lost in chat history.

The Smart Entrepreneurs Directory (SED) converts raw, unstructured WhatsApp chat intros into a living, structured, searchable, AI-enhanced directory. It empowers community admins and founders to discover peers, match synergies, export digital business cards, and analyze community growth—without requiring a server or database subscription.

1.2 Architectural Principles & Scope Boundaries

✅ In-Scope (Core Capabilities)

  • • Zero-Server Client-Side Persistence: 100% of member data, settings, and posts live in browser localStorage.
  • • Privacy-First Architecture: Member data is never sent to third-party databases. Direct user Gemini API keys.
  • • Dual Ingestion Engine: Single message parser, bulk WhatsApp group chat export parser, and manual form.
  • • AI Matchmaker: Profile compatibility scoring (0–10) and personalized WhatsApp outreach drafts.
  • • Geographic Map: World map rendering member distributions and top country statistics.
  • • Skills Exchange: 30-day auto-expiring board for skill offers and help requests.
  • • Business Card Engine: High-resolution PNG digital card exporter via html2canvas.
  • • Security Vault: SHA-256 Web Crypto PIN protection, 5-attempt rate-limiting, 30-min TTL, and typed deletion verification.

❌ Out-of-Scope (Non-Goals for v1.0)

  • • Multi-community SaaS tenancy (optimized for single community instance).
  • • Live cloud database synchronization (handled via JSON export/import).
  • • Direct WhatsApp Webhook bots (ingestion is file/text paste based).

3. Technical Specifications & Architecture

3.1 Technology Stack & BOM

Framework: React 18.3.1 (Concurrent Mode Rendering)
Build Tool: Vite 6.0.5 (ESM Bundling + HMR)
Styling: Tailwind CSS 3.4.17 + PostCSS + Autoprefixer
Icons: Lucide React 0.460.0
AI Integration: @google/generative-ai 0.21.0
Date Math: date-fns 4.1.0
Media Engine: html2canvas 1.4.1
Security Vault: Web Crypto API (SubtleCrypto SHA-256)
Testing Suite: Vitest 2.x + Testing Library React + jsdom

3.2 State Architecture (Tri-Split Context Pattern)

To eliminate re-render jank across unrelated components, state is divided into three separate memoized contexts:

MembersContext

Holds member database array, exchange posts, refresh triggers.

UIContext

Holds active tab, theme mode, API key, sidebar toggle, toast notifications.

FiltersContext

Holds search query string, stage filter selection, view mode toggle.

3.3 Security Vault & Cryptography

// SHA-256 Admin PIN Hash Formula
Hash = SHA-256("sed-pin-salt-" + userInputPIN)
Admin PINs are never stored in plain text. Failed attempts trigger a 5-minute lockout after 5 consecutive failures. Active sessions expire after 30 minutes of inactivity.
